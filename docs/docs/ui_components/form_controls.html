Form controls

Back on Forms, you built one from scratch. This page is the reference for what to actually put inside it: every built-in control, organized by the type of value it produces rather than by name — handy when you know you need "something that picks a ClosedRange<T>" but haven't settled on which control does that yet. They're all functions returning a FieldVisualizer, and they all live in the io.nacular.doodle.controls.form package.

info

These controls still need a Behavior explicitly installed, same as any other control. Everything below assumes BasicTheme or NativeTheme (Web, Desktop).

At a glance:

ProducesControls
Booleancheck, switch
T (interpolatable)slider, circularSlider
ClosedRange<T> (interpolatable)rangeSlider, circularRangeSlider
TtextField, radioList, singleChoiceList, spinButton, selectBox, form
T?optionalRadioList, optionalSingleChoiceList, optionalSelectBox
List<T>list, checkList, switchList
LocalFilefile
List<LocalFile>files
(structural)labeled, scrolling, framed

Doodle has many built-in controls that cover a range of data types for forms. These controls come as functions that return FieldVisualizers. They are all found within the io.nacular.doodle.controls.form package.

info

Usage of these controls still require explicit installation of Behaviors. Those shown below use behaviors from the BasicTheme orNativeTheme (Web, Desktop).

Structure​

These three don't produce a new type of value at all — they wrap an existing control to change how it's presented or laid out.

labeled​

Wraps a control and gives it a name — Type T, View: Container. This is what every example on the Forms page uses to attach labels like "Name" and "Age" to otherwise-unlabeled fields.

package forms import io.nacular.doodle.controls.form.field import io.nacular.doodle.controls.form.labeled import io.nacular.doodle.core.view fun <T> labeled() { //sampleStart labeled("Name", help = "Help text") { field<T> { view {} } } //sampleEnd }

scrolling​

Wraps a control in a scrollable region — Type T, View: ScrollPanel.

package forms import io.nacular.doodle.controls.form.field import io.nacular.doodle.controls.form.scrolling import io.nacular.doodle.core.View.Companion.fixed import io.nacular.doodle.core.view import io.nacular.doodle.geometry.Size fun <T> scrolling() { //sampleStart scrolling { scrollPanel.preferredSize = fixed(Size(100)) field<T> { view {} } } //sampleEnd }

framed​

Wraps a control so it can be styled and laid out as its own unit — Type T, View: Container.

package forms import io.nacular.doodle.controls.form.field import io.nacular.doodle.controls.form.framed import io.nacular.doodle.core.view import io.nacular.doodle.drawing.Color.Companion.Lightgray import io.nacular.doodle.drawing.paint import io.nacular.doodle.layout.Insets fun <T> framed() { //sampleStart framed { // configure the container builder insets = Insets(10.0) render = { rect(bounds.atOrigin, radius = 10.0, fill = Lightgray.paint) } field<T> { view {} } } //sampleEnd }

Custom Controls​

None of the above fit? Building your own is exactly as easy as creating a field directly — implement FieldVisualizer, or reach for the field DSL. Every control is really just a binding between a Field, its initial value, and a View.

Here's a Boolean field built from scratch, pairing a Label with a Switch:

package forms import io.nacular.doodle.controls.buttons.Switch import io.nacular.doodle.controls.form.Form.Valid import io.nacular.doodle.controls.form.field import io.nacular.doodle.controls.form.ifValid import io.nacular.doodle.controls.text.Label import io.nacular.doodle.core.container import io.nacular.doodle.geometry.Size import io.nacular.doodle.layout.constraints.constrain import io.nacular.doodle.text.AnnotatedString import io.nacular.doodle.utils.TextAlignment.Start //sampleStart fun switchField(text: AnnotatedString) = field { container { + Label(text).apply { textAlignment = Start } + Switch().apply { initial.ifValid { selected = it } // adopt initial value if present selectedChanged += { _,_,_ -> state = Valid(selected) // update field as switch changes } suggestSize(Size(40, 25)) state = Valid(selected) // ensure field is valid at beginning } focusable = false // ensure wrapping container isn't focusable layout = constrain(children[0], children[1]) { label, switch -> switch.left eq parent.right - 10 - readonly(switch.width) switch.centerY eq parent.centerY label.left eq 10 label.right eq switch.left - 10 label.centerY eq switch.centerY } } } //sampleEnd

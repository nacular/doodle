Catalog

You've just seen why controls need a Behavior to render at all, on Theming and Where's My View?. With that out of the way, here's the payoff: Doodle ships a full set of ready-made controls, so for a lot of common UI, you won't need to build Views from scratch the way you have been throughout this guide. This is the directory of all of them.

Rather than one long scroll through every control, they're grouped by what they're for:

CategoryControls
ButtonsPushButton,ToggleButton,CheckBox,RadioButton,Switch, HyperLink
Sliders & Value PickersSlider,CircularSlider,RangeSlider,CircularRangeSlider,ProgressBar,StarRater, SpinButton
Selection & TextLabel,TextField,SelectBox, Menu
Data DisplayList,Table,MutableTable,KeyValueTable,Tree,TreeTable, Carousel
Panels & LayoutGridPanel,SplitPanel,TabbedPanel, Accordion
Media & PickersPhoto,LazyPhoto,FileSelector,ColorPicker,MonthPanel, DaysOfTheWeekPanel

And two more pages nearby, covering territory this catalog doesn't:

  • Forms — combining several of the controls above into one typed, validated unit.
  • Form Controls — a second index, this one organized by the type of value a control produces rather than what it looks like. Handy when you know you need "something that picks a ClosedRange<T>" but haven't settled on which control yet.

Where to start: if you're not sure which page you need, skim the table above — the category names are meant to answer "what am I trying to do" rather than requiring you to already know a control's exact name.

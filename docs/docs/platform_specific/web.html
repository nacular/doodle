Web

Coming from Desktop, let's close things out with what's unique to running in the browser — and it's a satisfying place to land, since two things get promised earlier in this guide and finally paid off here.

Host apps in HTML elements​

Back on Displays, this was promised but not shown: launching a top-level Web app inside a specific HTML element, rather than letting it take over the whole page. Here it is — pass the element to application, and everything else about your app is completely unaffected. (Every example throughout this documentation is, in fact, hosted exactly this way.)

package htmlelementapp import usefulapp.HelloApp import io.nacular.doodle.application.application import org.w3c.dom.HTMLElement //sampleStart fun main(element: HTMLElement) { // launch app within element application(element) { HelloApp() } } //sampleEnd

Cleanup happens automatically, in more ways than one: closing the page tears down every app within it, and so does removing the element hosting a given app — or you can call shutdown on it explicitly, same as always.

Nested apps​

The other promise, from all the way back on Applications: a Doodle Web app can run inside another Doodle Web app. Place the nested app in a View that the host app manages, and it behaves exactly like a top-level app in every way that matters — the one difference is its lifecycle, which is now tied to that host View instead of the page.

Build one with an ApplicationViewFactory, available through the AppViewModule:

package io.nacular.doodle.docs.apps.nesting import io.nacular.doodle.application.Application import io.nacular.doodle.controls.ColorPicker import io.nacular.doodle.core.Display import io.nacular.doodle.docs.utils.doodleColor import io.nacular.doodle.drawing.opacity import io.nacular.doodle.layout.Insets import io.nacular.doodle.layout.constraints.constrain import io.nacular.doodle.layout.constraints.fill //sampleStart class InnerApp(display: Display): Application { init { // Shows a color picker display += ColorPicker(doodleColor opacity 0.75f).apply { changed += { _,_,new -> println(new) } } // The picker grows with the display, but is inset a little display.layout = constrain(display.first(), fill(insets = Insets(2.0))) } override fun shutdown() {} } //sampleEnd
package io.nacular.doodle.docs.apps.nesting import io.nacular.doodle.application.Application import io.nacular.doodle.application.ApplicationViewFactory import io.nacular.doodle.application.Modules.Companion.PointerModule import io.nacular.doodle.core.Display import io.nacular.doodle.core.center import io.nacular.doodle.core.height import io.nacular.doodle.core.width import io.nacular.doodle.drawing.Color.Companion.White import io.nacular.doodle.drawing.paint import io.nacular.doodle.geometry.Rectangle import io.nacular.doodle.geometry.centered import io.nacular.doodle.utils.Resizer import org.kodein.di.instance import kotlin.math.min //sampleStart class OuterApp(display: Display, appView: ApplicationViewFactory): Application { init { // NOTE: Any module needed by InnerApp MUST be provided to the factory. // PointerModule used here to enable interaction with the color picker. display += appView(modules = listOf(PointerModule)) { InnerApp(display = instance()) // Init inner app }.apply { suggestBounds(Rectangle( min(400.0, display.width - 20), min(300.0, display.height - 20) ).centered(at = display.center)) Resizer(this, movable = false) } display.fill(White.paint) } override fun shutdown() {} } //sampleEnd
package outerapp import io.nacular.doodle.application.ApplicationViewFactory.Companion.AppViewModule import io.nacular.doodle.application.Modules.Companion.PointerModule import io.nacular.doodle.application.application import io.nacular.doodle.docs.apps.nesting.OuterApp import org.kodein.di.instance fun main() { //sampleStart // NOTE: Modules used by the outer app are not available to the inner one. // The PointerModule is used here to allow resizing of the View that holds the inner app. application(modules = listOf(AppViewModule, PointerModule)) { OuterApp(display = instance(), appView = instance()) } //sampleEnd }
tip

Adding a nested app's View to the Display is what triggers that app's initialization. Removing the host View from the Display shuts it down.

Host arbitrary HTML elements​

This is the one that really opens things up: any HTML element can be embedded into your app as a View. That means a Doodle app can host React components — or anything else from the Web ecosystem — right alongside its own Views, not walled off from them.

Recap​

  • Launch a Web app inside a specific element with application instead of taking over the whole page — this is how every live example in this documentation actually runs.
  • A nested app behaves just like a top-level one, except its lifecycle is tied to the View hosting it rather than the page.
  • Any HTML element — including a whole React component — can become a View and sit directly alongside your Doodle content.
